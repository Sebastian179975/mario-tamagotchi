# Mariogotchi

Tamagotchi temático de Super Mario Bros desarrollado con HTML, CSS y JavaScript vanilla.

## Sprints

- **Sprint 1** — Maquetación retro (consola estilo NES)
- **Sprint 2** — Lógica de estado y DOM
- **Sprint 3** — Game loop y persistencia (localStorage)
- **Sprint 4** — Refactor, despliegue y ampliaciones

## Personajes

Mario · Luigi · Yoshi

## Tecnologías

HTML5 · CSS3 · JavaScript ES6
